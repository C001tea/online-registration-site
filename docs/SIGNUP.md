# Самостоятельная регистрация салонов

Владелец сам создаёт салон на странице `…/admin-panel/signup`: название, адрес сайта записи
(`nail-bar`), email, пароль. Сразу попадает в панель, проходит «Начало работы» (услуги, мастера,
график, Telegram) и получает ссылку на сайт записи для соцсетей. Пробный период — 14 дней
(`TRIAL_DAYS`); оплата — следующий этап, пока пробный период ничего не ограничивает.

Защита: сайт записи салона виден клиентам только после подтверждения email владельца;
не больше 5 регистраций в час с одного IP; поле-ловушка для ботов; служебные и занятые
адреса недоступны. «Забыли пароль?» — ссылка на email (2 часа, одноразовая), ответ
одинаковый для любого email, после сброса старые входы не действуют.

## Включить (один раз)

Регистрация и «Забыли пароль?» работают только с настроенной почтой.

1. **Почтовый сервис.** Любой с SMTP: Brevo, Resend, Postmark, Mailgun, Amazon SES.
   Добавьте и подтвердите в нём домен отправителя (`timepoint.tech`): сервис покажет записи
   SPF/DKIM — внесите их в DNS (Namecheap). Без этого письма попадут в спам.
2. **Пароль SMTP** → GitHub → Settings → Secrets and variables → Actions → секрет
   `EMAIL_HOST_PASSWORD`. Попадёт на сервер при следующем деплое.
3. **Настройки** → Actions → **Server settings** (по одной, значения из почтового сервиса):
   - `EMAIL_HOST` — например `smtp-relay.brevo.com`
   - `EMAIL_PORT` — `587` (или `465`)
   - `EMAIL_HOST_USER` — логин SMTP
   - `DEFAULT_FROM_EMAIL` — `TimePoint <no-reply@timepoint.tech>` (домен — подтверждённый в п. 1)
4. Проверка: в панели «Забыли пароль?» на свой email — письмо пришло.
5. **Открыть регистрацию**: Server settings → `SIGNUP_ENABLED` = `true`.

## Адрес сайта салона

Ссылка салона — `https://<адрес>.timepoint.tech` (`SALON_URL_TEMPLATE` = `https://{slug}.timepoint.tech`,
панель — `PANEL_URL` = `https://timepoint.tech`). Домены `timepoint.tech`, `www` (308 на основной) и `*.timepoint.tech`
подключены в Vercel, DNS домена — Vercel DNS (NS ns1/ns2.vercel-dns.com, меняются в кабинете get.tech).
Старый адрес `https://nail-salon-frontend.vercel.app/?salon=<адрес>` продолжает работать.

## Если что-то не так

- Письма не приходят — проверьте папку «Спам», записи SPF/DKIM, логин и пароль SMTP;
  ошибки отправки — в Sentry / логах сервера («Не удалось отправить письмо»).
- Заблокировать салон-нарушитель: Django admin → Companies → статус «Заблокирован»
  (сайт записи перестаёт открываться).
