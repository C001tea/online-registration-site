# Подключить новый салон

1. GitHub → Settings → Secrets and variables → Actions → секрет `NEW_SALON_PASSWORD`:
   пароль для владельца нового салона (не короче 8 символов, не только цифры). Сообщите его
   владельцу лично; после первого входа он меняет его в панели («Сменить пароль»).
2. Actions → **Create salon** → Run workflow: название, адрес (slug), логин владельца,
   при желании адрес и телефон салона. Сначала без галочки `confirm` — проверка данных;
   если всё хорошо — ещё раз с галочкой.
3. В логе — ссылки: сайт записи `…/?salon=<slug>` и вход в панель.
4. Свой адрес `<slug>.timepoint.tech`: Vercel → проект → Settings → Domains → добавить домен,
   в Namecheap — запись, которую покажет Vercel.
5. Владелец в панели: Настройки → Услуги → Мастера (+ доступ мастерам) → Графики;
   подробно — Панель → Помощь → «С чего начать».
